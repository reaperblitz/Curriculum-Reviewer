# ระบบตรวจหลักสูตรอัตโนมัติ (Curriculum Reviewer)

ระบบใช้ **OpenCode AI** ตรวจหลักสูตรมหาวิทยาลัยเทียบกับเกณฑ์บังคับ
ตัวอย่าง Blueprint ที่เคยผ่าน และมติกลั่นกรองในอดีต
**ไม่มีสคริปต์แปลง PDF** — AI อ่านไฟล์เองทั้งหมดผ่านเครื่องมือของ OpenCode

## วิธีใช้งาน (สำหรับอาจารย์/เจ้าหน้าที่)

1. วางไฟล์หลักสูตร `.pdf` ลงในโฟลเดอร์ `curriculums/`
2. push ขึ้นสาขา `main` หรือเปิด Pull Request — ระบบจะเริ่มตรวจให้อัตโนมัติ
3. ดูผลได้ 3 ทาง: 💬 Discord, 💬 คอมเมนต์บน PR, 📁 รายงานในโฟลเดอร์ `reports/`

ผลตรวจมี 3 แบบ: **PASS** (ผ่าน) / **NEEDS REVISION** (ต้องแก้ไข) / **FAIL** (ไม่ผ่านเกณฑ์บังคับ)
รายงานนี้เป็นเพียงความเห็นเบื้องต้นของ AI **การตัดสินขั้นสุดท้ายเป็นของคณะกรรมการกลั่นกรองหลักสูตร**

## วิธีติดตั้ง (สำหรับแอดมิน — ทำครั้งเดียว)

### 1. Secrets — ไม่บังคับ ✅
ท่าเดียวกับ wayla-work: ถ้ามี `OPENCODE_API_KEY` หรือ `ANTHROPIC_API_KEY`
ระบบจะใช้ผ่าน env อัตโนมัติ ถ้าไม่มีก็ลองรันเลย ขั้นไหน AI ไม่ตอบจะข้ามไป
งานจบเขียวเสมอ แล้วรายงานจะบอกตรง ๆ ว่าตรวจได้แค่ไหน (โหวตไม่ออก = ส่งคนตรวจ)

อยากคุณภาพสูงค่อยเพิ่ม:
| ชื่อ | ผล |
|---|---|
| `OPENCODE_API_KEY` | ใช้โมเดลของ OpenCode Console |
| `ANTHROPIC_API_KEY` | ใช้ Claude |
| `OPENAI_API_KEY` | สำรอง |
| `DISCORD_WEBHOOK_URL` | ไม่บังคับ (แต่แนะนำ) | ช่อง Discord → แก้ไขช่อง → การผสานรวม → Webhook |

### 2. ตั้งค่า Variables (ได้ที่เดียวกัน เมนู Variables)
| ชื่อ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `OPENCODE_MODEL` | (ว่าง = ให้ opencode เลือกดีฟอลต์เอง) | บังคับโมเดล เช่น `opencode/space-bunny-free` (ฟรี) หรือ `anthropic/claude-sonnet-4-5` (จ่ายเงิน คุณภาพสูง) |
| `AUDIT_STRICTNESS` | `standard` | `standard` ปกติ / `strict` เข้มงวด |

### 3. ไฟล์สำคัญใน repo
| โฟลเดอร์/ไฟล์ | หน้าที่ |
|---|---|
| `pdf/` | เกณฑ์ + ตัวอย่าง + มติในอดีต (AI อ่านเอง ห้ามลบ) |
| `curriculums/` | วางไฟล์รอตรวจที่นี่ |
| `reports/` | รายงานผลตรวจ + `INDEX.md` ประวัติทุกครั้ง |
| `scripts/audit.sh` | สคริปต์เดียวของระบบ: เริ่มงาน + ส่งพรอมต์ให้ OpenCode ทีละขั้น |
| `.opencode/agents/` | ตัวตน AI: `auditor` + กรรมการโหวต 3 เสียง |
| `opencode.jsonc` / `AGENTS.md` | ตั้งค่าและคำสั่งของ AI |

## การทำงาน 6 ขั้น (ใน `scripts/audit.sh`)
1. **สำรวจ** — AI อ่านโฟลเดอร์ `pdf/` หาเกณฑ์และตัวอย่างที่ตรงสายวิชา
2. **ตรวจ** — AI อ่านไฟล์เป้าหมายทั้งไฟล์ เขียนร่างผลตรวจภาษาไทย
3. **โหวต ×3** — กรรมการอิสระ 3 มุม (เกณฑ์ / คุณภาพวิชาการ / ความครบถ้วน) อ่านเองแล้วโหวต APPROVE/DENY
4. **สรุป** — รวมร่างกับผลโหวตตามเสียงข้างมาก เขียนรายงานฉบับเต็ม
5. **บันทึก** — เขียน `reports/audit_*.md` + ต่อท้าย `reports/INDEX.md` พร้อม SHA-256 ของไฟล์
6. **แจ้ง** — ส่ง Discord, คอมเมนต์ PR, ติดป้าย `needs-human-review` ถ้าไม่ผ่าน

ห้ามใช้ token ปลอม/แชร์คีย์ในโค้ด — คีย์ทุกอย่างอยู่ใน Secrets เท่านั้น
